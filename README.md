# 🚀 Student Productivity Dashboard

## 🔥 Overview

A full-stack web application where users can register, log in, and manage their daily tasks and study activities through a clean and modern dashboard.

---

## ⚙️ Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

---

## ✨ Features

- 🔐 User Authentication (Register & Login)
- 🔒 Protected Routes
- 📊 Dashboard with task tracking
- 📚 Study tracker
- 🎨 Modern UI with glassmorphism design
- 🚪 Logout functionality

---

## 📁 Project Structure

student-dashboard/  
├── client/   # Frontend (React)  
├── server/   # Backend (Node + Express)  

---

## 🚀 How to Run Locally

### 1️⃣ Clone Repository
git clone https://github.com/hariom-p1306/student-dashboard.git  

### 2️⃣ Setup Frontend
cd client  
npm install  
npm run dev  

### 3️⃣ Setup Backend
cd server  
npm install  
node index.js
